# Third-Party Licenses

SmartQuiz depends on open-source packages listed in `package.json` and `package-lock.json`.

Primary runtime technologies include:

- React
- Vite
- Tailwind CSS
- Radix UI
- Recharts
- Framer Motion
- Capacitor

Before public releases, generate or review the dependency license inventory and confirm compatibility with the project license.

Recommended command options:

```bash
npm ls --all
npm audit --omit=dev
```
